# 大肥鱼开挖掘机 — 测试代码与配置

## 硬件
- ESP32 DevKit V1（CH340，串口 COMx，115200）
- nRF24L01+ 模块（SOP，3.3V 独立供电，必须共地）
- WLtoys 6402 / 问南风 1:64 挖掘机（拆掉射频，用 LC116 H 桥接管）

## nRF24L01 接线（1→8）
GND / VCC / CE→D33 / CSN→D5 / SCK→D18 / MOSI→D23 / MISO→D19 / IRQ 悬空

## 电机接线（LC116 双路）
M1: D25/D26（实测 D25 高 = 右轮后退）
M2: D27/D32（实测 D27 高 = 左轮前进）
ESP32 GND 必须接车的电池负极

## 实测数据
- 8% duty 走 1 秒 ≈ 1~2 cm（最慢档，不打滑）
- 10% duty 转 2 秒 ≈ 60°（转向不稳，地面摩擦影响大）
- 1 cm ≈ 17 像素（433 宽的投屏画面里）
- 本 agent 读一张图 + 决策 ≈ 3 秒

## 关键坑
- nRF24L01 扫频道能收到 WiFi 信标（0x21 0x08 0x42 0x10 图案），别误判成遥控信号
- 这两台玩具的射频（BQ21856/B021856，24MHz 晶振）不在 nRF 协议体系里，抓不到
- 有线连接会拽车，转向标定全废
